📖 Setup & Help

PC (Windows): Plug in the V3 → open this file in Chrome or Edge → Connect → pick "RTL2838…" / "Blog V3". If Windows grabbed the dongle with a DVB driver, run Zadig once and install WinUSB on "Bulk-In, Interface 0".

Android: Plug the V3 into your phone with a USB-C OTG adapter → open this file in Chrome → Connect → allow the USB device. Attach the antenna and extend it (~19in for VHF).

Offline: This file is fully self-contained — no internet needed once it's saved on your device.

What it can hear: Analog only — your EMS/fire channels, Skywarn, NOAA, FRS, airband (AM), FM broadcast (WFM). It cannot decode MOSWIN P25 / DMR / NXDN (Springfield PD, Sheriff, Fire Ops, Willard buses, OTC). For those, use free SDRTrunk on your PC — also works offline.

Tips: Squelch around −55 to −60 dB is a good start. If audio is weak, raise RF Gain. If strong signals distort, lower it. ✓ next to a channel includes it in scanning; NOAA/ATIS are unticked by default since they never stop transmitting.
